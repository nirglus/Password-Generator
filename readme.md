# Password Generator

Personal full-stack project demonstrating a simple frontend-backend flow and first hands-on experience integrating Flask with a React frontend.

## Overview
A small web application that generates random passwords based on user input.
The frontend communicates with a backend API implemented using Flask.

## Tech Stack
**Frontend:** React, TypeScript, Tailwind CSS  
**Backend:** Python, Flask
